# Example 1: Full HA Stack Deployment

This example demonstrates how to use the `terraform-oci-alwaysfree-production-ha-stack` module to deploy a complete, production-ready infrastructure on Oracle Cloud Infrastructure (OCI) Always Free Tier.

## Overview

This configuration deploys:
- **Network**: VCN with Public, Private (Backend), and Database subnets.
- **Compute**: 2x ARM-based VMs (A1.Flex) for high availability.
- **Load Balancers**: Frontend and Backend Load Balancers.
- **Database**: Autonomous Transaction Processing (ATP) database.
- **Storage**: Object Storage bucket and Block Volumes.
- **Security**: Bastion service for secure SSH access.
- **Container Registry**: OCI Container Registry (OCIR) setup.

## Prerequisites

1.  **OCI Account**: An active Oracle Cloud Infrastructure account.
2.  **Terraform**: Installed on your local machine.
3.  **API Keys**: OCI API signing keys generated and uploaded to your user profile.

## Configuration

1.  **Navigate to the example directory:**
    ```bash
    cd examples/exemple-1
    ```

2.  **Create a `terraform.tfvars` file:**
    Copy the example file and fill in your credentials:
    ```bash
    cp terraform.tfvars.example terraform.tfvars
    
    # Or
    cp terraform.tfvars.example env/local.tfvars
    cp terraform.tfvars.example env/prod.tfvars
    ```

    Edit `terraform.tfvars` with your specific OCI credentials and settings.
    **Important**: Ensure `tenancy_ocid`, `user_ocid`, `fingerprint`, and `private_key_path` are correct. If you encounter `401-NotAuthenticated` errors, double-check these values and ensure the private key file exists and is readable.

    ```hcl
    # OCI Authentication
    tenancy_ocid     = "ocid1.tenancy.oc1..aaaa..."
    user_ocid        = "ocid1.user.oc1..aaaa..."
    fingerprint      = "xx:xx:xx..."
    private_key_path = "/path/to/your/private_key.pem" # Use absolute path if ~ expansion fails
    region           = "us-phoenix-1"

    # Project Settings
    project_name = "my-ha-app"
    environment  = "prod"

    # Database
    atp_admin_password = "YourStrongPassword123!"

    # Domains
    frontend_domain_name = "app.example.com"
    backend_domain_name  = "api.example.com"

    # GitHub Actions (Optional)
    github_actions_email = "ci@example.com"
    ```

## Usage

1.  **Initialize Terraform:**
    ```bash
    terraform init
    ```

2.  **Plan the deployment:**
    ```bash
    terraform plan -out tfplan.out
    # Or
    # terraform plan -var-file="env/local.tfvars" -out tfplan.out
    ```

3.  **Apply the configuration:**
    ```bash
    terraform apply tfplan.out
    # Or
    # terraform apply -var-file="env/local.tfvars" 
    ```

## Outputs

After a successful apply, Terraform will output key information, including:
- **Load Balancer IPs**: Public IPs for frontend and backend.
- **Database Connection Strings**: URLs to connect to the ATP database.
- **Bastion Information**: OCID and details for accessing private VMs.
- **Instance IPs**: Private IPs of the compute instances.

## Accessing Resources

### SSH to Private VMs
Use the OCI Bastion service to connect to your private instances:

```bash
terraform output bastion_connection_metadata
```

### Connect via SSH
```shell
ssh -i <your-private-key-path> -o ProxyCommand="ssh -i <your-private-key-path> -W <instance_private_ip>:22 <session_id>@host.bastion.<region>.oci.oraclecloud.com" -p 22 ubuntu@<instance_private_ip>
```

### Test Load Balancer
```shell
terraform refresh -var-file="env/local.tfvars"
terraform output frontend_load_balancer_public_ip
```

## Cleanup

To destroy the infrastructure and avoid using resources:

```bash
terraform destroy
```
